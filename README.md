# bobr-vm

`bobr-vm` is the future virtual-machine component of
[Bobr](https://github.com/aleksey-makarov/bobr).

Version 0.0.1 is an intentionally tiny, executable first release. It only
prints a greeting while the real project is being designed and implemented.
There is no stable interface yet.

```console
$ cargo run
Hello from bobr-vm! A proper Bobr VM project is coming soon.
```
